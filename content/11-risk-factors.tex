\subsection{Technical Risks}
\begin{itemize}
  \item \textbf{Prototype Maturity:} The self-custodial wallet is in public beta and not yet safe for real funds; external review before any production release
  \item \textbf{Platform Scalability:} Mitigated through cloud infrastructure and modular architecture
  \item \textbf{Security Breaches:} Comprehensive security audits and bug bounty program
\end{itemize}

\subsection{Market Risks}
\begin{itemize}
  \item \textbf{Bitcoin Price Volatility:} Business model agnostic to BTC price, focuses on security needs
  \item \textbf{Regulatory Environment:} Proactive compliance strategy, legal counsel engagement
  \item \textbf{Competition from Big Tech:} Anonymous marketplace creates differentiation
\end{itemize}

\subsection{Operational Risks}
\begin{itemize}
  \item \textbf{Key Person Dependency:} Solo founder today; the seed funds the first hires, and the protocol, papers and code are public
  \item \textbf{Pre-Incorporation:} No entity yet; incorporation on term sheet, with pre-seed investments converting into equity
  \item \textbf{Provider Churn:} Competitive revenue sharing, loud, proud community building
  \item \textbf{Customer Support Scale:} Automated systems, community support model
\end{itemize}
