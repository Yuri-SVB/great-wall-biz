% SECTION 16: MARKET SIZING (THREE SEGMENTS, THREE UNITS)
% ============================================================================
% STRUCTURAL RULE - READ BEFORE EDITING:
%   The three segments are counted in THREE DIFFERENT UNITS
%     S1 = individuals, S2 = institutions, S3 = companies
%   and are therefore NEVER summed into a single "subscriber" figure. The
%   previous model added Bitcoin users + password-manager users + vault users
%   + private-security customers into one 9,000,000 "subscriber" TAM; that sum
%   was dimensionally meaningless and has been removed.
%
%   The ONLY quantity that is legitimately comparable across the three
%   segments is ANNUAL PLATFORM REVENUE IN DOLLARS. Dollars may be summed;
